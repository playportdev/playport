Findings from this IPA, each filed and (except PLA-64, PLA-876) fixed for the final IPA:

* **PLA-850:** Playport's installer skipped every DLC depot. With the fix the classic install is
  53.5 GB (was 40.3 GB). The Witcher 3 1.32's Loading stall is not this, though: it is a GPU
  fault (PLA-880, below).
* **PLA-870/871:** Borderlands 2's VC++ 2008 prerequisite hung on a surface lock left by the 2005
  ATL installer's crashed process; with wine-unix 0206/0207 all four prerequisites exit 0.
* **PLA-872:** FreeType hinting through a 32-bit pointer faulted in a loop (unemulated `LD2`).
* **PLA-873:** FEX decoded past Mono's no-return calls into a method Mono had not yet patched; the
  launcher's main thread called `0xfeec7cc0` and Mono spun forever (black screen).
* **PLA-875:** DXVK returned a null allocation at the 2 GiB budget and its image constructor
  dereferenced it (The Witcher 3 crash).
* **PLA-64:** Borderlands 2's launcher dies when a logo link calls `Process.Start(url)`.
* **PLA-876:** pulling down Control Center leaves a fullscreen game minimized.
